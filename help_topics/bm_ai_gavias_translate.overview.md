---
title: BM AI Gavias Translate — Overview
---

**BM AI Gavias Translate** integrates with the **AI Translate** module to safely translate **Gavias Page Builder** JSON fields (including the base field `gva_pagebuilder_content`).

It extracts only human‑readable text keys, sends those values to your LLM with your per‑language prompt, and writes translations back **without changing the JSON structure, keys, ordering, or IDs**.

### Where to configure
- **Module settings:** `/admin/config/content/bm-ai-gavias-translate`
- **AI Translate prompts:** `/admin/config/ai/ai-translate`
- **Content translation settings:** `/admin/config/regional/content-language`
